# Healthcare Webinar Material Access Portal

A secure Laravel 12 application for managing healthcare webinar attendees and providing controlled access to webinar materials.

## Technology Stack

* Laravel 12
* PHP 8.4
* MySQL 8
* Bootstrap 5.3
* Alpine.js
* Laravel Breeze
* Spatie Permission
* Spatie Activitylog
* PDF.js

## Features

* Restricted attendee registration
* Email verification
* Role-based access control
* Webinar management
* Secure PDF viewing
* Access expiration management
* Activity tracking
* Reporting dashboard

## Roles

### Admin

* Manage webinars
* Manage attendees
* Manage materials
* Manage access
* View reports
* View logs

### Student

* Register using approved attendee email
* Verify email
* Login
* View assigned materials
